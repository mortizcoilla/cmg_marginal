§7

Auditoría del proyecto

7 hallazgos · 2026-09-30

El repositorio fue auditado en su estado actual (commit 5dbbfda). Detalle completo en la sección de auditoría (§7).

H1bloqueante

El repositorio no contiene código

Solo 2 archivos Markdown. Los src/*.py, datos y resultados descritos no están versionados; el Quick start no puede ejecutarse y las métricas no son reproducibles desde este repo.

H2alto

Fuga estructural por target proxy

Con un target proxy determinista, el MAE 2.53 roza el piso impuesto por el propio ruido de construcción (~1.7 USD/MWh). La mejora de +58.3% vs naive está inflada: el naive no conoce la hora; el modelo sí.

H3medio-alto

SARIMAX anómalo (posible bug)

MAE 24.19 = 4× peor que naive y 10× peor que LightGBM. Un SARIMAX bien especificado rara vez pierde así contra persistencia: revisar alineación de exógenas, escala y diferenciación en build_models.py.

H4medio

Chequeo de no-leakage insuficiente

El assert sobre los lags es correcto pero no alcanza: hour, GHI y elevation_deg determinan la forma del target proxy. No es leakage técnico, sí contaminación conceptual.

H5conocido

Cobertura IC 87.5% < 95%

Diagnóstico correcto en el reporte (asimetría del CMG) y remedio adecuado (conformal o cuantiles asimétricos). El §5 de este dashboard permite calibrar k y verificar la cobertura.

H6documentado

Exógenas sintéticas

Demanda y generación son sintéticas calibradas, no observaciones. Limita la calidad de las features de sistema; con demanda real el modelo debería mejorar, y las métricas serían comparables a operación.

H7consistencia ✓

Las cuentas internas cierran

MAE 2.53 con MAPE 4.6% implica media ≈55 USD/MWh, coherente con el duck (~28–87). RMSE/MAE ≈ 2.45 → colas pesadas, consistente con la cobertura IC baja. Fechas y splits cuadran.

→acción

Receta mínima de reparación

1) Versionar código + results/predictions_test.csv. 2) Reportar métrica sobre CMG diario real. 3) Auditar el SARIMAX. 4) Conformar la banda (§5). 5) Sustituir el proxy con CMG horario real (CEN+).

Reproducir el pipeline
  1. python3 src/build_hourly_proxy.py — CMG diario → horario
  2. python3 src/build_features.py — 39 features + EDA
  3. python3 src/build_models.py — SARIMAX + LightGBM
  4. python3 -m http.server 8000 → /dashboard/
Fuentes de datos

CMG diario: CEN vía Energía Abierta (8 barras, 2023–2025).
Meteorología: NASA POWER horaria (GHI, DNI, temp, viento, nubosidad).
Posición solar: pvlib. Demanda/generación: sintético calibrado.

Honestidad del artefacto

Las series, bandas e importancias de este dashboard son reconstrucciones generadas desde el perfil y las métricas documentadas en REPORTE_FINAL.md — no los CSV originales (no versionados). Sustituir por results/predictions_test.csv cuando exista.
